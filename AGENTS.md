# Consignes pour les agents

Avant toute intervention dans ce dépôt, lire `.collab/README.md`, les tickets ouverts
de `.collab/tickets/`, `COORDINATION.md`, puis les journaux de `coordination/`.
Les tickets sont le canal commun ; les journaux précisent les réservations de fichiers.

Lire aussi `CLAUDE.md` pour les conventions techniques du projet. Ses préférences
d'outils de lecture concernent Claude Code ; chaque agent utilise ses outils disponibles.

Ne pas écraser, annuler, déplacer ni inclure dans un commit les modifications de
l'autre agent sans passation explicite. Respecter les réservations du protocole.
