<p>
  This page covers the <strong>technical approach</strong> behind Pétanque Meet, a project
  <strong>still in progress</strong>: the app is on its way to the Play Store and the App Store. To find
  a game, the <a href="/petanque-meet/">map of games</a> (in French) is the place.
</p>

<h2>The need</h2>
<p>
  You want to play, but nobody is free to make up the doubles? Games between friends are set up over the
  phone, and club tournaments on posters at the boulodrome. Pétanque Meet puts both on one map: games
  looking for players, how many are missing, and upcoming tournaments with their poster.
</p>

<h2>One server for the website and the app</h2>
<p>
  The map started on this website, and the Unity app came next. Both talk to the <strong>same
  server</strong>: one Supabase Edge Function, in TypeScript, is the only way in. The tables have no
  public access rule at all; only that function reads and writes them. A game posted in the app shows up
  on the website, and the other way round.
</p>
<p>
  The function holds every rule: validation, seats left, abuse limits per player and per hashed IP
  address. Its refusal messages are written in French, and the app shows them as they are. Copying them
  into the app would have made a second source of truth, one that would drift the day the server adds a
  case.
</p>

<h2>Browse without an account, act with one</h2>
<p>
  The map is open to everyone. Posting a game, joining one, following a tournament or reporting needs an
  account: Sign in with Apple on iPhone, Google on Android (in the browser, with PKCE). The first games
  predate accounts and relied on a device id and a per-game secret, so the app still sends both until
  those games expire. Nobody loses control of their game.
</p>

<h2>Public content, so moderation</h2>
<ul>
  <li>First names and tournament texts are checked by the server: no links, no markup.</li>
  <li>A poster stays private until a moderator approves it.</li>
  <li>Every game and tournament has "Report or hide", which can also hide all games from one
  organizer.</li>
  <li>The account can be deleted from the app: upcoming games are cancelled and the first name is
  removed.</li>
</ul>

<h2>A Unity interface written in Python</h2>
<p>
  The app's screens are not laid out by hand in the Unity editor. Each screen is described by a Python
  script, then built into a prefab by <strong>PrefabFusion</strong>, Ludiven Studio's in-house tool. The
  scripts enforce a style charter (text sizes, grid, radii, colour roles): no size or colour is hard-coded.
  Changing a margin or a tint happens once, and every screen follows. That is what makes <strong>five
  palettes, each in light and dark</strong>, possible.
</p>

<h2>Privacy</h2>
<p>
  The GPS position never leaves the phone: centring the map and the distances are computed on the device.
  Reminders before a game are local notifications, with no token sent to a server. Audience measurement
  (Umami) is anonymous and cookieless: fixed event codes, with no account or device id.
</p>

<h2>Five languages, checked</h2>
<p>
  The texts live in a spreadsheet translated into French, English, Spanish, German and Italian. One script
  exports the file the app reads, and another blocks the release if a key is missing, if a French string
  is left in the code, or if a character is missing from the embedded font. The empty box in place of a
  "ß" shows up before release, not after.
</p>

<h2>Where the project stands</h2>
<p>
  The web map is live. The Android app can already be downloaded from the
  <a href="/petanque-meet/telecharger/">download page</a> (in French), and the Play Store and App Store
  releases are under way.
</p>
